# Visual Direction

<!-- cspell:ignore DDMMHBC shmup -->

This page separates the confirmed screen composition from temporary artwork.
It describes the intended look, not a final art specification.

## Confirmed composition and style

- The target output is a 16:9 PC image. A centered 3:4 portrait playfield sits
  inside it, leaving space on both sides for later framing or HUD content. The
  brief does not define an exact pixel resolution or final HUD layout.
- Backgrounds are 3D, while characters use sprites rendered before gameplay
  rather than live character models in the playfield.
- The presentation should evoke mid-to-late-2000s arcade shmups. This is a
  reference for the overall presentation, not a specification to copy a
  particular game's art.

## Provisional artwork

DDMMHBC is the codename and provisional title; the final title is not settled.
Original character art is also not available yet. Until it is, the project uses
an interim static sprite rendered from one view of a Unity Cube. It can be
replaced without changing the intended playfield composition. The current
[Cube proxy image][cube-proxy] is generated by the editor-only
[proxy renderer][cube-tool] ([issue #11][boot-scene]).

## Deferred decision

The choice of a third-party shmup framework or project-owned bullet-pattern
tools remains with the maintainer; see the [decision issue #6][decision] and
its [candidate survey][survey]. That choice does not change the
screen ratio or placeholder-art status recorded here.
