# Project Overview

<!-- cspell:ignore DDMMHBC URP shmup -->

This page records the project's shared baseline so contributors can start from
the same facts. It describes requirements; it does not claim that every planned
feature or delivery workflow has been implemented.

## Confirmed requirements

- The project is a one-shot, roughly three-minute vertical bullet-hell shooter
  for Windows and Linux PC. The brief gives the intended experience length, but
  does not specify lives, continues, exact stage count, or other detailed rules.
- The project uses Unity Editor `6000.3.26f1` with the Universal Render Pipeline
  (URP).
- The game combines 3D backgrounds with character sprites prepared before
  gameplay. The [visual page](visual-direction.md) explains the planned screen
  composition.

## Provisional details

- **DDMMHBC** is the project's codename and provisional title; the final game
  name is not settled.
- A static sprite rendered from one view of a Unity Cube is the interim
  character visual. It is a replaceable proxy, not final character art. The
  current asset is
  [`CubeProxy.png`](../../Assets/Art/Placeholders/CubeProxy.png),
  generated by [`RenderCubeProxy.cs`](../../Assets/Editor/RenderCubeProxy.cs)
  ([boot-scene issue #11][boot-scene]).

## Deferred decision

The project has not chosen how enemy bullet patterns will be authored. The
completed [framework survey in issue #16][survey] records candidate evidence
but makes no selection. The separate [maintainer decision in issue #6][decision]
remains the place to choose a third-party framework or a project-owned approach.
